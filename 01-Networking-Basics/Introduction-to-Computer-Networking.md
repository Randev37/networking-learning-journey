# Introduction to Computer Networking

## 1. What is Computer Networking?

Computer networking is the process of connecting two or more computing devices to share information, resources, and services.

## 2. Why is Computer Networking Important?

- Sharing files and information.
- Sharing hardware such as printers.
- Communication between devices.
- Accessing the Internet.
- Sharing network resources.

## 3. Examples of Computer Networks

- Home Wi-Fi network
- University computer laboratory network
- Office network
- Internet

## 4. What I Learned

I learned that computer networking allows different devices to communicate and share resources with each other.
